#  AI Blog Assistant 

##  Project Overview

AI Blog Assistant is a production-ready Generative AI chatbot application built using Google Gemini API, LangChain, and Streamlit.

The application helps users generate structured, SEO-friendly blog content through an interactive chat interface while maintaining conversational memory and optimized token usage.

This project demonstrates real-world AI engineering concepts including:
- LLM Integration
- Prompt Engineering
- Conversation Memory
- Token Optimization
- Logging
- Modular AI Architecture
- Streamlit-based Deployment

---

#  Features

##  Gemini API Integration
- Google Gemini GenAI API integration
- Secure API key management using environment variables
- Modular LLM architecture
- Structured request and response handling
- Proper exception handling
- Logging of API calls and errors
- Token usage optimization

---

##  Advanced Prompt Engineering
- Structured system prompts
- Role-based prompting
- Domain-specific instructions
- Reusable prompt templates
- Conversation-aware prompting

---

##  Conversation Memory
- Implemented using LangChain Message History
- Remembers previous interactions
- Optimized using `n_messages` to reduce token consumption

---

##  Streamlit User Interface
- Chat-style interface
- Real-time response rendering
- Conversation history display
- Loading spinner
- User-friendly layout
