# Exploring Prompt Engineering Techniques

This repository is created for learning and experimenting with different Prompt Engineering techniques used in Large Language Models (LLMs) like GPT, Gemini, Claude, and Llama.

The main goal is to understand how different prompts affect model responses, reasoning, accuracy, and output quality.

---

#  Techniques Explored

- Zero-Shot Prompting
- Few-Shot Prompting
- Chain of Thought (CoT)
- Role Prompting
- Instruction-Based Prompting
- Contextual Prompting
- Self-Consistency Prompting
- ReAct Prompting
- Tree of Thoughts (ToT)

---

# Technologies Used

- Python
- Gemini api/ Groq api
- Jupyter Notebook

---

# Purpose of Exploration

- Learn Prompt Engineering concepts
- Understand LLM behavior
- Compare prompting strategies
- Improve GenAI practical knowledge
- Prepare for AI/ML interviews
